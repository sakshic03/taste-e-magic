# 🍴 Taste-e-Magic

**Taste-e-Magic** is an online food ordering website developed as my Diploma 5th Semester internship project.

The website provides a simple and user-friendly interface where users can explore food items, select their desired menu items, and place an order through an easy-to-use order form.

## 🌐 Project Overview

Taste-e-Magic was developed independently, from the initial idea and design to implementation.

### ✨ Key Features

- 🍽️ Browse available food items
- 🛒 Select food items from the menu
- 📝 Order form with automatically filled food details
- 📱 Order submission connected with WhatsApp
- 🎨 Simple and user-friendly interface
- 📱 Responsive website design

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**
